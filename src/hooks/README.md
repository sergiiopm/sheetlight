# src/hooks

React hooks that connect app-level state to the UI.

- `use-workbook-tabs.ts` — open workbooks (document tabs), native open plumbing
  (dialog, "Open with", second instance, drag & drop) and window title
- `use-shortcuts.ts` — app-level keyboard shortcuts (Ctrl+N, Ctrl+O, Ctrl+W,
  Ctrl+Tab). Grid shortcuts belong to `src/grid` / `src/model`.

# src/lib

Small, framework-independent helpers.

Current contents:

- `theme.ts` — light/dark theme (same behaviour as Doclight)
- `utils.ts` — `cn()` class name helper
- `is-tauri.ts` — detects whether the app runs inside Tauri

Planned: number formats (general, number, currency, %, date, custom), locale
handling for value entry and display (default: Windows regional settings).
